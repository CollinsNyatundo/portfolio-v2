# Bench object image prompts

Each photograph uses the same camera, surface and lighting setup so the objects sit together on one work surface. Save generated images to `public/images/objects/<slug>.avif` at 800 by 1000 pixels (aspect ratio 4:5) with metadata stripped, then set `exists: true` for that slug in `content/objects.ts`.
